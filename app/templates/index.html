Credit risk scoring on Lending Club 36-month loans

A probability of default (PD) model and a loss given default (LGD) model, combined into an expected loss per loan: EL = PD × LGD × EAD. Models are trained on loans issued up to mid-2014 and tested on the full 2015 vintage, which none of them saw. Every figure on this page is read from models/metrics.json, written by the training script.

4Probability of default

Logistic regression and LightGBM, both inside a scikit-learn pipeline (median imputation with missing-value flags, scaling, one-hot encoding, and target encoding of the free-text job title, cross-fitted so no loan sees its own label) and trained with balanced class weights. Balanced weights push probabilities up, so a sigmoid fitted on the validation vintage maps them back to default rates without changing the ranking. The selected model is then refitted on train and validation, keeping that sigmoid. The deployed model uses only fields known at application time; the full model adds monthly payment, state and three more credit bureau counts.

5Decision threshold

A loan is approved when its expected margin exceeds its expected loss, (1 − PD) × m > PD × LGD × CCF, which gives t* = m / (m + LGD × CCF). With the net margin set to m = {{ m.policy.margin }}, training LGD {{ m.policy.lgd_mean_train|num }} and CCF {{ m.policy.ccf_train|num }}, the threshold is PD < {{ m.policy.threshold|pct }}. 6Loss given default

LGD = 1 − recoveries / EAD at default, for charged-off loans, bounded to [0, 1]. EAD at default is the principal still owed; recoveries are cash collected after charge-off. None of the payment columns used to build the target are features.

7Expected loss

EAD is the funded amount times a credit conversion factor (CCF = {{ m.policy.ccf_train|num }}), the average share of principal still owed when training loans defaulted. The backtest compares it with the loss actually realized on the 2015 loans.

9Limitations

  • 36-month loans only: 60-month vintages had not run off far enough to be tested out of time.
  • Interest rate and sub-grade are Lending Club's own pricing, so the model partly relearns it.
  • The test year defaulted more than the calibration year; PDs would need periodic recalibration.
  • CCF is a single portfolio average; the margin in the threshold is an assumption.
